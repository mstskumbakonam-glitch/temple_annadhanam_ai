# Demo videos

Put recorded clips here (e.g. `crowd.mp4`) and register them with
`python ../scripts/seed_demo.py --video crowd.mp4` (run from `backend/`).

* Video files in this folder are git-ignored: never commit footage of real people.
* Use only footage you have permission to use (your own temple recording with
  the management's consent, or a public dataset whose licence allows it).
* Cameras using these files are labelled **RECORDED** in the API and dashboard.
